      How the Diagnosis Works
      1
      pH Validation — Henderson-Hasselbalch check
      Calc. pH = 6.1 + log₁₀( HCO₃⁻ ÷ (0.03 × PaCO₂) ) If |Calc. pH − Entered pH| > 0.1 → inputs inconsistent
      2
      Direction — pH < 7.40 → acidaemia · pH ≥ 7.40 → alkalaemia
      3
      Respiratory Acidosis — PaCO₂ ≥ 45, pH < 7.40
      pH <7.30 or >7.50 → Acute (×1) · pH 7.30–7.50 → Chronic (×4) Expected HCO₃ = 22 − ((40 − PaCO₂)/10) × multiplier (±20%) Below → + Met. Acidosis · Above → + Met. Alkalosis
      4
      Metabolic Acidosis — PaCO₂ < 45, pH < 7.40 · Winters' formula
      Expected PaCO₂ = 1.5 × HCO₃⁻ + 8 (±10%) Below expected → + Resp. Alkalosis · Above → + Resp. Acidosis
      5
      Metabolic Alkalosis — PaCO₂ ≥ 35, pH ≥ 7.40
      Expected PaCO₂ = 0.7 × HCO₃⁻ + 21 (±10%) Urinary Cl⁻ < 20 → chloride-responsive · ≥ 20 → chloride-resistant
      6
      Respiratory Alkalosis — PaCO₂ < 35, pH ≥ 7.40
      pH >7.50 → Acute (×2) · pH 7.40–7.50 → Chronic (×5)
      7
      Anion Gap (for all metabolic acidosis diagnoses)
      Corr. AG = Na⁺ − (Cl⁻ + HCO₃⁻) + 0.25 × (44 − Albumin) AG ≤ 12 → NAGA · AG > 12 → HAGMA HCO₃ gap = Na⁺ − Cl⁻ − 36 → delta-delta (HAGMA + met.alk or + NAGA)

      Quick Tutorial
      Step 1 of 4
      Entering Values
      Two ways to enter ABG data
      Sliders & fields
      Drag any slider or click the number field next to it and type a value directly. The diagnosis card updates in real time with every change.
      Preset cases
      Scroll to the bottom of the input panel — preset buttons load classic cases (Normal, Resp. Acidosis, Met. Acidosis, etc.) instantly so you can explore how each one looks.
      Electrolytes & SIG
      Na, Cl, albumin, lactate and other electrolytes refine the anion gap, correct for hypoalbuminaemia, and drive the SIG / BDE tab analysis.
      Reading the Diagnosis
      Understand what the result card shows
      Acidosis Alkalosis Normal
      The card colour and tag tell you the primary disorder at a glance. The main line gives the full diagnosis including compensation status.
      Decision path
      Below the diagnosis card, each numbered step shows exactly how the conclusion was reached — pH classification, primary disorder, expected compensation, AG correction, and more. Ideal for teaching rounds.
      Copy & Export
      Use Copy to paste the diagnosis text into notes, or Export PDF to generate a formatted single-case report.

      Advanced Tools
      SIG analysis, Batch import, and more
      SIG / BDE Tab
      The SIG / BDE Analysis tab calculates the Strong Ion Gap and Base Deficit of Extracellular fluid — useful for detecting unmeasured anions from ketones, toxins, or uraemia.
      Batch Import
      Use the Batch Import tab to analyse multiple patients at once. Download the Excel template, fill in one row per patient, re-upload, and export all results as Excel or PDF.
